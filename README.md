## 🎯 프로젝트 소개

### 클리어 (Clear)

아르바이트를 하는 대학생·사회초년생이 임금 체불, 주휴수당 미지급 같은 부당대우를 겪었을 때, **혼자서도 상황을 파악하고 증거를 모아 해결까지 갈 수 있도록** 돕는 서비스입니다.

| 단계 | 내용 |
| --- | --- |
| 1. 상황 확인 | 내가 겪은 일이 부당한지 진단 |
| 2. 권리 확인 | 실제 지급액과 비교해 주휴수당 등 차액 계산 |
| 3. 증거 정리 | 사건 타임라인 구성, 부족한 증거 자료 안내 |
| 4. 해결 방법 선택 | 사장님과의 원만한 소통 템플릿 또는 외부 상담·신고 가이드 |

> 기획은 계속 발전 중이며, 세부 내용은 바뀔 수 있습니다. 변경 과정은 [회의록](https://github.com/pudding-lab-2026/capstone/wiki)에서 확인할 수 있습니다.
